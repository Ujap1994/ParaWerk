# Point

> **Where:** *Features* tab → arrow of **Plane** → **Point** · **Needs:** nothing (coordinates) or what the
> point is built on

A reference point is a point in space: a point to build a plane or an axis through, the center of a hole
to measure from. It does not change the body.

## Step by step

1. Choose **Point** in the arrow of **Plane**.
2. Choose the *Type*: enter *X*, *Y*, *Z*, or fill the fields in the 3D view or the tree.
3. Click **✓**.

## Types

| Type | Built from | Default |
|---|---|---|
| **Coordinates** | *X*, *Y* and *Z* (also as equations) | 0, 0, 0 |
| **Center of an edge or face** | The center of a circle or arc, the middle of any other edge, or the center of a face's area | |
| **Where an axis meets a plane** | An axis and a plane that is not parallel to it | |

## Tips

- Points follow the part like [planes](plane.md) do.
- A point is drawn as a small marker; it can be picked in the 3D view and in the tree.
