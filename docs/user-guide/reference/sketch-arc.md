# Arcs

> **Where:** *Sketch* tab → *Draw* group → **Arc** (its arrow offers all three variants) · **Key:** A ·
> **Needs:** an open sketch

| Variant | How to draw |
|---|---|
| **Arc** (center) | Click the center and the start point, then move in the direction the arc should run and click the end point |
| **3-point arc** | Click the start and the end point, then a point the arc passes through |
| **Tangent arc** | Click the end point of a line or arc, then where the arc should end: it continues the line or arc without a kink (*tangent*) |

![A line continued by a tangent arc, a slot, a hexagon and a rectangle with a rounded and a beveled corner](../../images/screenshots/sketch-tools.png)

## Step by step

1. Press **A** (the variant used last) or choose a variant in the arrow next to **Arc**.
2. Click as in the table; radius and sweep angle are shown next to the cursor.
3. **Esc** leaves the tool.

## Tips

- [Dimension](sketch-dimension.md) an arc with one click: it gets a radius (R).
- Two arcs of the same radius: *Equal*; arcs with the same center: *Concentric*.
- For rounded corners of existing lines, [Sketch fillet](sketch-fillet-chamfer.md) is quicker.
