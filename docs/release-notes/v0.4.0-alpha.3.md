# ParaWerk 0.4.0-alpha.3 – fixes for parts of several bodies

A small alpha on top of [0.4.0-alpha.2](v0.4.0-alpha.2.md), with the fixes made right after it. All
features of alpha.2 are described in its release notes and in the [user guide](../user-guide/README.md).
It is an alpha to try out and give feedback on, not yet a tool for productive work.

## Fixes

- **Parts of several bodies:** shells, drafts, threads, face fillets and full rounds work on the body their
  faces belong to. Before, a shell failed and a thread cut nothing when another body overlapped the one it
  was on. The faces of one such feature must belong to one body; otherwise the feature says so.

## Faster

- **Free-form faces** of sweeps, lofts and springs are meshed for the 3D view about six times faster: a
  spring of ten turns builds in about 0.4 s instead of 1.3 s, and looks the same. STL exports keep their
  precision.

## Tests

- The reference suite, which builds parts and changes their early features, now covers the features of
  Phase 3 as well: 47 parts with 115 edits rebuild without lost references in every CI run.

## Which file do I need?

| System | Download |
|---|---|
| Windows 10/11 (Intel/AMD) | `ParaWerk-0.4.0-alpha.3-win-x64-setup.exe` (installer) or `…-win-x64-portable.exe` |
| Windows on ARM | `ParaWerk-0.4.0-alpha.3-win-arm64-setup.exe` or `…-win-arm64-portable.exe` |
| macOS (Apple Silicon and Intel) | `ParaWerk-0.4.0-alpha.3-mac-universal.dmg` (or `…-mac-arm64.dmg` / `…-mac-x64.dmg`) |
| Linux | AppImage, `.deb`, `.rpm`, `.pacman`, Snap, Flatpak or `.tar.gz` for x64 (`x64`, `x86_64`, `amd64`) or arm64 (`arm64`, `aarch64`) |

The builds are not signed with a developer certificate yet, so the system asks once before the first
start (on Windows: *More info → Run anyway*). [Getting started](../user-guide/getting-started.md#install)
shows how to confirm on each system.

## Known limitations

- Not in this alpha yet: lofts with guide curves, splitting bodies, feature scope and moving or copying
  bodies; assemblies (Phase 4).
- Part files with the features of 0.4.0-alpha.2 and later (format version 10) cannot be opened by
  ParaWerk 0.4.0-alpha.1.

Read the [user guide](../user-guide/README.md) for every tool, step by step.
