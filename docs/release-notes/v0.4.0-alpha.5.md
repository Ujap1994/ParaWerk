# ParaWerk 0.4.0-alpha.5 – linear patterns go into the part

A small alpha on top of [0.4.0-alpha.4](v0.4.0-alpha.4.md), with what testing patterns along edges turned
up. All features are described in the [user guide](../user-guide/README.md) and, function by function, in
the [function reference](../user-guide/reference/README.md). It is an alpha to try out and give feedback
on, not yet a tool for productive work.

## Linear patterns go into the part

A straight edge has a direction of its own, which follows how its sketch line was drawn: the bottom and
the top edge of a plate extruded from a rectangle point opposite ways. A pattern along the top edge
therefore sent its copies off the part, where a cut removes nothing.

- **Into the part:** when you pick the direction of a linear pattern, ParaWerk turns it towards the rest of
  the part, from the features you copy. The top and the bottom edge of the plate now both pattern a column
  of holes across it.
- **An arrow** in the 3D view starts at the features you copy and shows which way the copies go.
- **Other direction** turns the copies round as before; your choice stays.
- Copies that miss the part get their own warning, which points to **Other direction**.
- Patterns in parts you saved before do not change.

## Which file do I need?

| System | Download |
|---|---|
| Windows 10/11 (Intel/AMD) | `ParaWerk-0.4.0-alpha.5-win-x64-setup.exe` (installer) or `…-win-x64-portable.exe` |
| Windows on ARM | `ParaWerk-0.4.0-alpha.5-win-arm64-setup.exe` or `…-win-arm64-portable.exe` |
| macOS (Apple Silicon and Intel) | `ParaWerk-0.4.0-alpha.5-mac-universal.dmg` (or `…-mac-arm64.dmg` / `…-mac-x64.dmg`) |
| Linux | AppImage, `.deb`, `.rpm`, `.pacman`, Snap, Flatpak or `.tar.gz` for x64 (`x64`, `x86_64`, `amd64`) or arm64 (`arm64`, `aarch64`) |

The builds are not signed with a developer certificate yet, so the system asks once before the first
start (on Windows: *More info → Run anyway*). [Getting started](../user-guide/getting-started.md#install)
shows how to confirm on each system.

## Known limitations

- Not in this alpha yet: lofts with guide curves, splitting bodies, feature scope and moving or copying
  bodies; assemblies (Phase 4).
- Part files with the features of 0.4.0-alpha.2 and later (format version 10) cannot be opened by
  ParaWerk 0.4.0-alpha.1.

Read the [function reference](../user-guide/reference/README.md) for every function, step by step.
